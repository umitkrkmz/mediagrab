# Audio Track Language Codes

**[🇹🇷 Türkçe sürüm](language-codes.tr.md)** · **[← Back to main README](../README.md)**

---

The language code shown in MediaGrab's "Audio Track" section (when downloading a video, or under **Settings → Default Audio Track**) is the two-letter [ISO 639-1](https://en.wikipedia.org/wiki/ISO_639-1) code — the same one YouTube itself uses.

The table below lists every ISO 639-1 code, sorted alphabetically by language name. Which languages an actual video has varies from video to video; this page is just here to help you match a **code to its language**.
